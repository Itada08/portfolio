# Portfólio — Chico

Site pessoal com minha trajetória acadêmica, projetos e habilidades.
Feito com HTML, CSS e JavaScript, e publicado no GitHub Pages.

## Seções
- Sobre mim
- Atividades acadêmicas
- Projetos (com filtro por área)
- Feiras e eventos
- Sites desenvolvidos
- Habilidades e contato

## Como editar
Os textos, projetos, sites e habilidades ficam no início do arquivo `script.js`.
O e-mail, o GitHub e o LinkedIn ficam no final do `index.html`.

## Como rodar
Abra o arquivo `index.html` no navegador.
